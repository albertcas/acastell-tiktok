# acastell-tiktok

Vídeos de 30 s o menos para el TikTok de acastell.dev: conceptos tech explicados con animación, palabras en pantalla y sound design sintetizado (sin locución).

Cada carpeta de `videos/` trae el MP4 (1080x1920, 9:16) y el texto del post. Los vídeos se generan con una skill propia de Claude Code y se programan desde Metricool, que descarga el MP4 desde la URL pública de este repo.
